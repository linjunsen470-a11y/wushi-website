临街门店开业请舞狮，流程不必安排得很复杂。对多数餐饮店、零售店和生活服务门店来说，先确认门前空间与管理要求，再把**点睛、简短表演、采青吐幅和进店巡游**排顺，就能完成一场清楚、紧凑的开业仪式。

## 门店开业舞狮，先确认四件事

1. **门前能否停留**：查看人行通道、台阶、花篮和门头布置后，还剩多少可用空间。
2. **锣鼓是否需要报备**：临街商铺、社区底商和商业街的管理要求不同，应提前向物业、场地方或相关管理方确认。
3. **顾客从哪里进店**：表演区不要堵住主要入口，也不要占用消防通道。
4. **下雨时在哪里演**：重庆天气变化较快，户外活动应提前确定遮雨位置或缩短版备用流程。

如果门前空间狭窄、地面有明显坡度，或者周边不适合长时间敲锣鼓，可以减少门外动作，把主要仪式放在店门口固定区域完成。是否适合高桩或较大阵容，应由团队查看现场照片、尺寸和地面条件后再判断。

## 一个简洁的开业舞狮流程

门店开业常见的安排可以控制在几个核心环节内：

| 环节 | 安排重点 |
| :--- | :--- |
| 迎宾亮相 | 狮子在门店入口附近亮相，给顾客留出通行空间 |
| 嘉宾点睛 | 提前确认参与人员、站位和主持人口播 |
| 地面表演 | 根据门前可用空间调整动作与队形 |
| 采青吐幅 | 提前确认采青道具和祝福文字，并安排清理 |
| 进店巡游 | 先收好易碎物品，避免狭窄区域拥堵 |
| 合影收尾 | 在门头或品牌背景前完成集体合影 |

如果当天还有剪彩、揭牌或负责人致辞，建议先确定主仪式的时间点，再让舞狮团队配合衔接。不要同时安排多个环节抢占门口，否则嘉宾站位、顾客进店和拍摄机位容易互相影响。

## 临街门店容易忽略的场地问题

### 台阶、斜坡和湿滑地面

重庆不少门店入口带台阶或坡道。活动前应拍清楚地面高差，并检查雨后是否湿滑。花篮、电线、音响和活动物料也要提前移出表演动线。

### 门头与店内净高

狮头抬起和演员站立动作都需要空间。雨棚、灯箱、吊灯和门头装饰较低时，应提前告知团队，由领队调整动作，避免现场临时取消环节。

### 采青后的清理

如果使用生菜采青，结束后会有少量菜叶需要清理。餐饮店、商场内铺或对卫生要求较高的场地，可以提前询问是否需要改用红包、卷轴等替代形式，具体以现场要求为准。

### 围观人群与拍摄位置

舞狮可能吸引顾客驻足，但不能把“聚集人气”当成确定的经营效果。更实际的做法是提前划出表演区和通行区，并给摄影人员保留一个正面机位，让点睛、吐幅和门头画面能够完整记录。

## 咨询前准备这份信息清单

向舞狮团队咨询时，建议一次提供：

- 开业日期、开始时间和详细地址；
- 门店入口的正面照片及左右两侧环境照片；
- 门前大致可用宽度、是否有台阶或斜坡；
- 是否需要点睛、采青、吐幅、剪彩配合或进店巡游；
- 物业或场地方对锣鼓、占用公共区域的要求；
- 下雨时可使用的备用区域。

这些信息比只问“舞狮多少钱”更有用。团队需要结合日期、地点、阵容、流程和场地条件判断配置，具体费用可参考[重庆开业舞狮报价说明](/guide/chongqing-lion-dance-price)，执行前也可对照[舞狮现场检查清单](/guide/preparation-guide)逐项确认。

## 常见问题

**门店开业一般需要几只狮子？**

没有统一数量。门前空间有限时，应优先保证动线清楚和动作安全；场地较宽、仪式规模较大时，再考虑增加阵容。可先提供现场照片，由团队给出适合的配置建议。

**锣鼓可以直接在街边敲吗？**

不同街区、物业和场地的要求并不相同，不能一概而论。建议在确定演出前向实际管理方确认允许的区域、时段和音量要求。

**下雨还能表演吗？**

要看雨势、地面防滑和遮雨条件。可提前准备门厅、雨棚下方等备用位置，必要时缩短户外环节；具体是否能安全执行，应由现场负责人和团队共同判断。

**需要提前多久联系？**

档期受日期、时间和项目规模影响，没有固定答案。活动信息基本确定后即可咨询；节假日或集中开业日期，越早确认越便于安排。
