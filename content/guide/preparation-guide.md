活动前确认好场地条件，可以减少现场临时调整。下面这份检查清单涵盖空间、电力、物业报备和应急预案。

## 先确认这三样
**层高够不够、有没有更衣休息的地方、物业报没报备。**

层高不够，托举和高桩做不了；没地方更衣，队员只能在大堂换，场面难看；物业没打招呼，锣鼓一响可能有人来拦。

## 舞狮执行的核心检查清单

### 1. 场地空间：别让狮子“憋屈”
- **地面高度**：
    - 普通表演：建议净高不低于 **3 米**（避免狮子直立时触碰到顶灯）。
    - 高桩表演：净高必须在 **4.5 米以上**（桩高 + 人高 + 安全冗余）。
- **舞台尺寸**：
    - 地面双狮：至少需要 4m x 4m 的开阔地。
    - 高桩：桩体占地约 2m x 10m，表演区建议不小于 6m x 12m。

### 2. 物业报备：避开红线
- **禁噪时段**：重庆不少商场或写字楼在 10:00 前限制高音量鼓乐。若仪式安排在 9:00，应提前确认是否允许执行。
- **采青碎渣**：采青涉及碎生菜，部分五星级酒店或高档专柜极度反感地面碎渣。需提前沟通是“采生菜”还是“采利是（红包）”。
- **巡游路径**：狮子是否进电梯？是否经过昂贵的艺术品陈列区？

### 3. 后勤备场：关乎专业形象
- **更衣区**：请提供一个约 10 平方米的隐蔽区域（会议室、储藏间或空铺）。**严禁让队员在洗手间或活动背景板后更衣。**
- **饮用水**：舞狮是重体力劳动，每场表演后请为每位队员准备至少一瓶常温矿泉水。

### 4. 音频与电力
- **鼓乐现场**：通常不需要电力。
- **创意项目**：如涉及 LED 夜光狮或需要背景音乐伴奏，需提供 220V 电源及音频接口（3.5mm 或 XLR）。

## 那些“只有专业执行才知道”的细节

1. **地面的摩擦力**：重庆潮湿天气多。如果户外是大理石地面且有积水，狮子跑动极易滑倒。需备好拖把或防滑地毯。
2. **交通到场缓冲**：如果是早间活动，要考虑重庆早高峰。建议要求团队提前 60-90 分钟到达指定卸货区。
3. **红封（红包）的准备**：
    - **采青红包**：挂在生菜里。
    - **巡游红包**：狮子进店时由负责人递交红包（狮口接红），寓意利是。

## 舞狮活动执行时间轴

| 阶段 | 任务清单 |
| :--- | :--- |
| **活动前 7 天** | 锁定团队、预付定金、告知物业、确认巡游路线。 |
| **活动前 3 天** | 确认条幅内容、确认天气预案（如果是户外）。 |
| **活动前 1 天** | 向舞狮队发送准确的卸货定位和现场执行负责人电话。 |
| **活动当天 (H-1.5h)** | 团队到场、卸货、进入更衣区、对接流程。 |
| **活动当天 (H-0.5h)** | 队员换装完毕、道具检查、主持人最后对稿。 |
| **仪式结束** | 领队带队安静撤场、清理现场生菜碎屑。 |

## 常见问题解答 (FAQ)

**Q：我们可以临时改时间吗？**
A：小范围调整（30分钟内）通常可以协调。但如果改到下午或第二天，可能会因为撞档导致无法提供服务，建议定下后非必要不调整。

**Q：我们需要给舞狮队员发个人红包吗？**
A：这不是强制的。但在重庆习俗中，开业时给队员每人一个 10-20 元的“利是”确实能极大鼓舞士气。

**Q：舞狮会把地毯弄坏吗？**
A：普通地毯不会。但如果是极昂贵的真丝地毯，狮爪的抓地力可能会有轻微痕迹，建议提前铺设一层保护垫。

**Q：现场如果发生意外摔倒怎么办？**
A：是否配有意外险、具体保障范围及双方责任，应在签约前根据保险条款和服务合同确认。现场出现异常时，应立即暂停演出并按照安全预案处理。

**Q：可以要求狮子在表演时喊我们公司的口号吗？**
A：狮子不会说话，但我们可以通过鼓乐的停顿配合主持人的口播，或者由狮子吐出印有口号的条幅。
